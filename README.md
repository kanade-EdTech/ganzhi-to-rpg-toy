# 🔮 生辰造化：天干地支 RPG 先天数值推演器 (`ganzhi-to-rpg-toy`)

> **你或你的 OC 的生日先天数值 丨 生辰造化，天干地支**
>
> 将传统子平命理（四柱八字、五行生克、十神分布、地支藏干、十二长生）严密转化为具象化、可溯源的 **RPG 角色先天属性面板、核心词条与动态玩法规则**。

---

## ✨ 核心特性

- **🌌 跨越万年的生辰与历史年号输入（`-5000` ~ `+5000` 年）**
  - **日期与时制双解耦**：支持「公历 / 农历（含闰月）」与「现代 24 小时制 / 传统十二时辰（区分早晚子时）」自由混搭。
  - **历代年号检索**：集成 DILA 与 CeJS 权威历史年表（[`data/history/all-era-years.csv`](data/history/all-era-years.csv)），支持按「朝代 → 帝王/年号 → 纪年」一键定位历史或架空 OC 生辰。
- **☯️ 严谨透明的四柱排盘与权重算法**
  - 自动推算四柱干支、二十四节气月令提纲、地支藏干（本气/中气/余气，严格遵循 **「藏干加成 ≤ 主柱 1/3」** 铁律）与十二长生状态倍率（`0.85x ~ 1.25x`）。
  - 面板每一项 RPG 数值均支持鼠标悬停回溯四柱干支来源，拒绝“黑盒随机数”。
- **⚔️ 十神即词条，五行即底色**
  - **五行能量底盘**：木（生机/恢复）、火（爆发/精神）、土（坚韧/防御）、金（锋芒/穿透）、水（灵动/敏捷）。
  - **十神进阶词条**：将十神映射为 10 项核心 RPG 属性，并自动评定单神独旺（如`【天命欧皇】`、`【背水天煞孤星】`）或双神联动称号（如`【镇狱剑仙·食神制杀】`、`【文武通神·伤官配印】`）及灵根品阶（`SSR · 天灵根` 等）。
- **📸 一键分享与双命格同屏对比**
  - 支持导出高清国风命格长图（PNG）、复制 Markdown 设定表格，以及存入对比槽位直观比较两名角色的五行互补与十神差异。

### 2. 进阶玩法生态延展（Rule-Driven RPG Framework）

本项目的底层规则可直接延展为完整的游戏系统（详见 [`DESIGN.md` 第五章](DESIGN.md)）：
- **同器异效（相对论道具唤醒）**：道具仅定义自身的「天干（五行+阴阳）」属性。不同日主的玩家使用同一件五行道具时，根据 $\text{十神} = f(\text{日主}, \text{道具干支})$ 唤醒截然不同的十神效果（例如同一把【丙火】法剑，甲木用之唤醒「食神回蓝」，庚金用之唤醒「七杀背水」，戊土用之唤醒「偏印减CD」）。
- **官杀雕琢（被克跨期历练补偿）**：「克我者为官杀，玉不琢不成器」。阵营或属性被克的一方在当前即时战斗中处于战术劣势，但在战后结算时可额外获得高额**「雕琢经验」**，将眼前的逆境转化为长线境界突破的资粮。
- **相生共鸣（情缘与帮派正和社交）**：情缘结契与帮派大阵侧重于「五行相生（印比相扶 / 食伤吐秀）」，让不同八字的玩家在组队与社交中实现双向增益。
- **AI 基线模拟 + 后期「强力锚定道具」**：前期通过 AI 跑通大体数值分布基线，中后期投放规则级「锚定道具」（锁底线、转溢出、逆转墓绝），兼顾先天宿命感与终局平衡。
